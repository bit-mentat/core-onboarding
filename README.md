# Bitcoin Core onboarding

These documents from [chaincodelabs](https://github.com/chaincodelabs/bitcoin-core-onboarding/tree/main) provide an overview of the Bitcoin Core codebase.

Archived in late 2023, many changes have been merged since (ex. Tx Graph, libevent removed) and is now outdated.

To reflect the current status of Bitcoin core, these documents were updated with Claude Opus 5.
